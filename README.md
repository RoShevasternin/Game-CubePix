# CubePix — the cube museum

**CubePix** is a calm pixel art puzzle by [Lewydo](https://lewydo.com/): fill the cubes layer by layer, and famous paintings, wonders of the world and little pixel treasures come to life, each with a museum label and a true story.

- 🌐 Site: <https://cubepix.lewydo.com/>
- 🎮 Free web demo (the first floors): <https://cubepix.lewydo.com/play/>
- 🔒 Privacy policy: <https://cubepix.lewydo.com/privacy.html>

This repository hosts the game's website and web demo (GitHub Pages). They are built automatically from the game's own source, so please don't edit the files here by hand: changes would be overwritten by the next build.
